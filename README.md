# My Little Netflix

Aplicación web cliente que funciona como una base de datos de películas. Está hecha con HTML, CSS y JavaScript, siguiendo el patrón **MVC** (Modelo-Vista-Controlador). Los datos se guardan en el `localStorage` del navegador.

Práctica de la asignatura **Tecnologías Web**.

## Funcionalidades

- **View:** muestra el título, el director y la portada de una película.
- **Add:** abre el formulario para crear una película nueva.
- **Create:** guarda la nueva película (el título es obligatorio).
- **Edit / Update:** modifica los datos de una película existente.
- **Delete:** elimina una película, pidiendo confirmación antes.
- **Reset:** restaura las películas iniciales.
